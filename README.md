### Getting started

```bash
git clone https://github.com/Raimal-Raja/CPP_Programming_Data-Structures_Algorithms.git
cd CPP_Programming_Data-Structures_Algorithms
```

Use a JDK and compile individual exercises separately; repeated class names may appear across folders. Example:

```bash
javac "Practice/Runner.java"
```

The JDK was unavailable for compilation checks in this review.
